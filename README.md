# Atividade 4 — Exercício sobre Git (FizzBuzz)

## Objetivo
Receber um número inteiro `N` e, para os números de 1 até `N`, imprimir:
- `FizzBuzz` se o número for múltiplo de 3 e 5;
- `Fizz` se for múltiplo de 3;
- `Buzz` se for múltiplo de 5;
- o próprio número caso não seja múltiplo de 3 nem de 5.

## Como executar
É necessário ter o Java instalado.

```bash
javac FizzBuzz.java
java FizzBuzz
```
Digite um número inteiro positivo quando solicitado.

## Exemplo
Entrada: `15`

Saída esperada:

```text
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```
